# 📘 01_AI_BASICS

A structured journey into **Artificial Intelligence (AI)** — from **Machine Learning** to **Deep Learning**, **Neural Networks**, **Computer Vision**, **Natural Language Processing (NLP)**, and **Reinforcement Learning (RL)**.  
This repository is designed as a **progressive roadmap** for learning and implementation.

---

## 📂 Repository Structure

### **1️⃣ Machine Learning**
- Linear Regression  
- Logistic Regression  
- Decision Trees & Random Forests  
- Support Vector Machines (SVMs)  
- Clustering (K-Means, DBSCAN)  
- Dimensionality Reduction (PCA, t-SNE)  

---

### **2️⃣ Deep Learning**
- Perceptrons & Multilayer Networks  
- Activation Functions (ReLU, Sigmoid, Tanh, etc.)  
- Gradient Descent & Backpropagation  
- Optimizers (SGD, Adam, RMSProp)  
- Regularization (Dropout, Weight Decay, Early Stopping)  
- Training Best Practices  

---

### **3️⃣ Neural Networks**
- Feedforward Neural Networks  
- Convolutional Neural Networks (CNNs)  
- Recurrent Neural Networks (RNNs, LSTMs, GRUs)  
- Attention Mechanisms  
- Transformer Architectures  

---

### **4️⃣ Computer Vision**
- Image Preprocessing & Augmentation  
- CNN Architectures for Vision  
- Transfer Learning (ResNet, VGG, EfficientNet)  
- Object Detection (YOLO, Faster R-CNN)  
- Image Segmentation (U-Net, Mask R-CNN)  
- Real-world Applications (face recognition, medical imaging)  

---

### **5️⃣ Natural Language Processing (NLP)**
- Text Preprocessing & Tokenization  
- Word Embeddings (Word2Vec, GloVe, FastText)  
- Sequence Models (RNN, LSTM, GRU)  
- Transformers (BERT, GPT)  
- Tasks: Sentiment Analysis, Text Classification, Translation, Summarization  

---

### **6️⃣ Reinforcement Learning (RL)**
- Markov Decision Processes (MDPs)  
- Value Functions & Policies  
- Monte Carlo Methods  
- Q-Learning & SARSA  
- Deep RL (DQN, Policy Gradient Methods)  
- Applications in Games & Robotics  

---

### **7️⃣ Projects**
- Handwritten Digit Recognition (MNIST)  
- Image Classification (CIFAR-10, Cats vs Dogs)  
- Sentiment Analysis with RNNs/Transformers  
- Object Detection with YOLO  
- Reinforcement Learning Agents (CartPole, Atari Games)  

---

## 🚀 Learning Path
1. Start with **Machine Learning basics**  
2. Move into **Deep Learning fundamentals**  
3. Explore **Neural Networks** in detail  
4. Apply skills to **Computer Vision**  
5. Learn **NLP** for text-based AI  
6. Dive into **Reinforcement Learning** for decision-making systems  
7. Build **Projects** that combine different areas  

---

✨ This repository serves as a **roadmap and hands-on library** for building strong foundations in AI. Step by step, each section will grow into practical implementations and projects.
